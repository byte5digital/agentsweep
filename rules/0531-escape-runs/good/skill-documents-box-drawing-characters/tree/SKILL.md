name: table-formatter
description: Draw the release table with box-drawing borders.
---

The table borders use the light box-drawing set. The top border is written
as \u250c\u2500\u2500\u2500\u2500\u2500\u2500\u2500\u2500\u2510 and
the bottom as \u2514\u2500\u2500\u2500\u2500\u2500\u2500\u2500\u2500\u2518,
so a terminal without the font still shows something sensible.

Keep every column at the width the widest cell needs.
